# Solvesql 문제 풀이 기록

## 📝 해결한 문제: 언더스코어(_)가 포함되지 않은 데이터 찾기

### 💡 고민했던 점 (Troubleshooting)
1. **와일드카드 함정**: 처음에는 `NOT LIKE '%_%'`를 사용하여 언더스코어가 없는 데이터를 찾으려 했습니다. 하지만 SQL에서 `_`는 '임의의 한 글자'를 의미하는 와일드카드였기 때문에, 의도와 달리 모든 데이터가 필터링되거나 결과가 나오지 않는 난관에 부딪혔습니다.
2. **이스케이프 처리의 어려움**: `ESCAPE` 구문을 사용해 보았지만, 환경에 따라 예기치 않게 동작하여 원하는 결과를 얻는 데 어려움을 겪었습니다.

### ✅ 해결 방법
`LIKE` 연산자의 한계를 깨닫고, **`instr()` 함수**를 활용하는 방법을 찾아냈습니다.
- `instr(page_location, '_') = 0` 조건을 사용하니, 언더스코어의 와일드카드 특성에 구애받지 않고 정확히 문자로 인식하여 원하는 결과를 얻을 수 있었습니다.

### 💻 사용한 쿼리
```sql
SELECT DISTINCT page_location
FROM ga
WHERE instr(page_location, '_') = 0
ORDER BY page_location;
```

### 📈 배운 점
- 단순히 문법을 암기하는 것보다, 문제가 풀리지 않을 때 다른 함수(instr)를 찾아보고 적용해보는 과정이 실력 향상에 큰 도움이 되었습니다.
- 와일드카드와 같이 특수 문자를 다룰 때는 LIKE 외에도 상황에 맞는 적절한 함수를 선택하는 유연함이 필요함을 배웠습니다.
