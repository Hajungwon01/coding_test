# [solvesql] 제목이 모음으로 끝나지 않는 영화

- **난이도**: 레벨 2
- **정답률**: 36.41% (작성일 기준)
- **문제 링크**: [solvesql - 제목이 모음으로 끝나지 않는 영화](https://solvesql.com/problems/film-ending-with-consonant/)

---

## 📝 문제 설명

DVD Rental Store 데이터베이스의 `film` 테이블은 영화 정보를 담고 있습니다. 

17세 미만 학생이 DVD 대여점에 혼자 와서는 대여할 수 없는 영화 중, 제목이 모음(`'A'`, `'E'`, `'I'`, `'O'`, `'U'`)으로 끝나지 않는 영화를 찾고 싶습니다. 조건에 맞는 영화 제목(`title`)을 출력하는 쿼리를 작성해주세요. (다른 컬럼은 출력되지 않아야 합니다.)

### 영화 등급(rating) 참고 사항
* **G**: 모든 연령 관람 가능
* **PG**: 아동 관람 시 부모 지도 필요
* **PG-13**: 13세 미만 관람 시 부모의 주의 필요
* **R**: 17세 미만은 부모 또는 21세 이상과 동반 관람만 가능 (**혼자 대여 불가**)
* **NC-17**: 18세 미만 관람 불가 (**혼자 대여 불가**)

---

## 🔍 접근 방식

1. **서브쿼리를 통한 1차 필터링**: 17세 미만 학생이 혼자 대여할 수 없는 등급인 `NC-17`과 `R`에 해당하는 영화 데이터를 인라인 뷰(서브쿼리)로 먼저 추출합니다.
2. **메인쿼리를 통한 2차 필터링**: 서브쿼리에서 걸러진 데이터 중, `LIKE` 연산자와 `AND` 조건을 활용하여 영화 제목(`title`)의 마지막 글자가 모음(`A`, `E`, `I`, `O`, `U`)으로 끝나지 않는 데이터만 최종적으로 선택합니다.
3. **출력 제한**: 조건에 부합하는 영화의 `title` 컬럼만 깔끔하게 조회합니다.

---

## 💻 SQL 풀이

```sql
SELECT title
FROM 
(
  SELECT * FROM film
  WHERE rating = 'NC-17' OR rating = 'R'
)
WHERE title NOT LIKE '%A' 
  AND title NOT LIKE '%E'
  AND title NOT LIKE '%I'
  AND title NOT LIKE '%O'
  AND title NOT LIKE '%U';
