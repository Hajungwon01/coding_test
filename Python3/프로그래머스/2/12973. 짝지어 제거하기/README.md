## 문제 설명

짝지어 제거하기는, 알파벳 소문자로 이루어진 문자열을 가지고 시작합니다. 먼저 문자열에서 같은 알파벳이 2개 붙어 있는 짝을 찾습니다. 그다음, 그 둘을 제거한 뒤, 앞뒤로 문자열을 이어 붙입니다. 이 과정을 반복해서 문자열을 모두 제거한다면 짝지어 제거하기가 종료됩니다. 문자열 S가 주어졌을 때, 짝지어 제거하기를 성공적으로 수행할 수 있는지 반환하는 함수를 완성해 주세요. 성공적으로 수행할 수 있으면 1을, 아닐 경우 0을 리턴해주면 됩니다.

예를 들어, 문자열 S = `baabaa` 라면

b **aa** baa → **bb** aa → **aa** →

의 순서로 문자열을 모두 제거할 수 있으므로 1을 반환합니다.

### 제한사항

- 문자열의 길이 : 1,000,000이하의 자연수
- 문자열은 모두 소문자로 이루어져 있습니다.

### 입출력 예

| s | result |
|---|--------|
| baabaa | 1 |
| cdcd | 0 |

---

## ❌ 내 코드 (틀린 풀이)

```python
def solution(s):
    answer = 1
    
    contained = set(s)
    tmp = len(contained)
    
    if len(s) % 2 != 0:
        answer = 0
    else:
        while tmp > 0:
            if len(s) == 0:
                answer = 1
                break
            for c in contained:        
                s = s.replace(c*2, '')
            tmp -= 1
            contained = set(s)
            
    if len(contained) != 0:
        answer = 0
    return answer
```

## 🔍 왜 틀렸는가? — 오답 원인 분석

### 1. `replace`는 한 번에 모두 지워버린다 (순서 무시 문제)

`str.replace(c*2, '')`는 문자열 내의 **모든** 해당 쌍을 동시에 제거합니다.  
하지만 실제 문제는 **한 쌍을 제거한 뒤 앞뒤가 붙어서 새로운 쌍이 생기는 연쇄 반응**이 핵심입니다.

예시: `"abba"`

- 올바른 과정: `ab`**`bb`** 아님 → `a`**`bb`**`a` → 아님 → `a` + `a` = `aa` → 제거 → 성공 (1)
- `replace` 방식: `s.replace('bb', '')` → `"aa"` → `s.replace('aa', '')` → `""` → 우연히 맞음

더 치명적인 예시: `"abccba"`

- 올바른 과정: `ab`**`cc`**`ba` → `ab` + `ba` = `abba` → `a`**`bb`**`a` → `aa` → **`aa`** → 성공 (1)
- `replace` 방식 (루프 순서에 따라): `cc` 제거 → `abba`, `bb` 제거 → `aa`, `aa` 제거 → `""` → 우연히 성공
- 하지만 알파벳 set의 순서가 보장되지 않아 **다른 순서로 replace하면 결과가 달라질 수 있습니다.**

### 2. `set`의 순서는 보장되지 않는다

`for c in contained`에서 `set`은 **반복 순서가 불확실**합니다.  
어떤 문자를 먼저 제거하느냐에 따라 결과가 달라지는 경우가 생깁니다.

### 3. 반복 횟수(`tmp`)가 불완전하다

`while tmp > 0`에서 `tmp`는 고유 문자 종류 수입니다.  
짝 제거 후 새로운 문자 종류가 생기거나 사라지는 경우를 정확히 반영하지 못합니다.

### 4. 시간 복잡도 문제 (효율성)

`str.replace()`는 매번 전체 문자열을 순회하므로 최악의 경우 O(N²) 이상입니다.  
문자열 길이가 최대 1,000,000이므로 효율성 테스트에서 시간 초과가 발생할 수 있습니다.

## ✅ 올바른 풀이 — 스택(Stack) 활용

### 스택(Stack)이란?

스택은 **후입선출(LIFO, Last In First Out)** 구조의 자료구조입니다.  
마지막에 넣은 것을 가장 먼저 꺼냅니다.

```
push → [  a  b  b  ] ← pop
             ↑ top
```

### 파이썬에서 스택 사용법

파이썬에서는 **리스트(`list`)를 스택으로 그대로 사용**합니다.

| 연산 | 코드 | 설명 |
|------|------|------|
| push (삽입) | `stack.append(x)` | 스택의 맨 위에 원소 추가 |
| pop (제거) | `stack.pop()` | 스택의 맨 위 원소 제거 후 반환 |
| top 확인 | `stack[-1]` | 맨 위 원소 확인 (제거 안 함) |
| 비어있는지 확인 | `len(stack) == 0` 또는 `not stack` | 스택이 비어있으면 True |

```python
stack = []

stack.append('a')     # ['a']
stack.append('b')     # ['a', 'b']
stack.append('b')     # ['a', 'b', 'b']

print(stack[-1])      # 'b'  ← top 확인
stack.pop()           # ['a', 'b']  ← 'b' 제거

print(not stack)      # False (비어있지 않음)
```

### 스택을 이용한 풀이

```python
def solution(s):
    stack = []
    
    for c in s:
        # 스택의 top과 현재 문자가 같으면 → 짝 제거
        if stack and stack[-1] == c:
            stack.pop()
        # 다르면 → 스택에 push
        else:
            stack.append(c)
    
    return 1 if not stack else 0
```

### 동작 과정 예시: `"baabaa"`

| 현재 문자 | 스택 top | 동작 | 스택 상태 |
|-----------|----------|------|-----------|
| `b` | (없음) | push | `['b']` |
| `a` | `b` | push (다름) | `['b', 'a']` |
| `a` | `a` | pop (같음! `aa` 제거) | `['b']` |
| `b` | `b` | pop (같음! `bb` 제거) | `[]` |
| `a` | (없음) | push | `['a']` |
| `a` | `a` | pop (같음! `aa` 제거) | `[]` |

최종 스택이 비었으므로 → `1` 반환 ✅

### 시간 복잡도 비교

| 방법 | 시간 복잡도 | 비고 |
|------|-------------|------|
| `replace` 반복 | O(N²) 이상 | 비효율적, 정확성도 불안정 |
| 스택 활용 | **O(N)** | 문자열을 한 번만 순회 |

## 💡 핵심 정리

- 짝 제거처럼 **"바로 이전 것과 비교"하는 문제는 스택이 최적**입니다.
- 파이썬 리스트는 스택으로 바로 사용 가능 (`append` / `pop` / `[-1]`)
- `str.replace()`는 순서를 보장하지 않고 비효율적이므로 이런 문제엔 부적합합니다.
